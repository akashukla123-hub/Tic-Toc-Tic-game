# 🎮 Interactive Tic-Tac-Toe Game

A classic, lightweight, and responsive **Tic-Tac-Toe** game built using Vanilla JavaScript, HTML5, and CSS3. This project demonstrates basic game logic, DOM manipulation, and responsive web design.

## ✨ Features
*   **Modern UI:** A sleek dark-themed interface with smooth transitions.
*   **Smart Logic:** Automatically detects winning combinations (rows, columns, and diagonals) and draw matches.
*   **Real-time Status:** Displays which player's turn it is and announces the winner instantly.
*   **Fully Responsive:** Optimized for both Desktop and Mobile screens.
*   **One-Click Reset:** Quickly restart the game without refreshing the page.

## 🛠️ Built With
*   **HTML5:** Semantic structure for the game board.
*   **CSS3:** Flexbox/Grid for layout and custom styling for X and O players.
*   **JavaScript (ES6):** Array-based logic to handle game states and win conditions.
